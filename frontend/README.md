# greenblock frontend

Tech used:

- React 19
- TypeScript
- Vite
- React Router
- localStorage for local MVP state

## Implemented routes

- `/login`
- `/home`
- `/teammates/new`
- `/teammates/:teammateId`
- `/messages/:teammateId`
- `/calendar`

## What works now

- Login flow
- Workspace home
- Teammate registration form
- Analysis result page
- Message recommendation page
- Calendar add and delete

## Build

```bash
npm run build
```

# greenblock 유스케이스 모델

## 1. 문서 목적

이 문서는 greenblock의 액터, 유스케이스를 정의하고, 주요 사용자 시나리오를 유스케이스 다이어그램과 유스케이스 명세 형태로 정리한다.

## 2. 액터 정의

### 2.1 1차 액터

| 액터 | 설명 |
| --- | --- |
| 사용자 | greenblock에 로그인해 팀원 등록, 분석, 메시지, 캘린더 기능을 사용하는 주체 |

### 2.2 2차 액터

| 액터 | 설명 |
| --- | --- |
| AI 분석 서비스 | 만세력 구조화 결과를 바탕으로 협업 가이드를 생성하는 외부 또는 별도 실행 서비스. 현재는 Ollama, 향후 OpenAI 포함 |
| 소셜 로그인 제공자 | 향후 카카오 소셜 로그인 구현 시 인증 결과를 제공하는 외부 인증 시스템 |

| ID | 유스케이스 | 주 액터 |
| --- | --- | --- |
| UC-01 | 로그인한다 | 사용자 |
| UC-02 | 워크스페이스 홈을 조회한다 | 사용자 |
| UC-03 | 팀원을 등록한다 | 사용자 |

| UC-06 | 만세력 결과를 OCR 처리한다 | 사용자 |
| UC-07 | 협업 가이드를 생성한다 | 사용자 |
| UC-08 | 추천 메시지를 참고해 메시지를 작성한다 | 사용자 |

## 4. 유스케이스 명세

### 4.1 UC-03 팀원을 등록한다

| 항목 | 내용 |
| --- | --- |
| 목적 | 협업 대상 팀원의 기본 정보와 출생 정보를 등록한다 |
| 주 액터 | 사용자 |
| 선행조건 | 사용자가 로그인 상태여야 한다 |
| 후행조건 | 팀원이 목록과 상세 화면에서 조회 가능해야 한다 |
| 기본 흐름 | 1. 사용자가 팀원 등록 화면으로 이동한다. 2. 이름, 역할, 이메일, 출생 정보를 입력한다. 3. 시스템이 입력값을 저장한다. 4. 팀원 상세 화면으로 이동한다. |
| 예외 흐름 | 필수값 누락 시 저장하지 않고 오류 메시지를 표시한다 |

### 4.2 UC-07 협업 가이드를 생성한다

| 항목 | 내용 |
| --- | --- |
| 목적 | 팀원과의 협업에 맞는 성향 해석과 대화 방식을 생성한다 |
| 주 액터 | 사용자 |
| 보조 액터 | AI 분석 서비스 |
| 선행조건 | 팀원 정보가 등록되어 있어야 하며 만세력 결과가 입력되어 있어야 한다 |
| 후행조건 | 성향 해석, 일 스타일, 대화 가이드, 메시지 예시가 표시된다 |
| 기본 흐름 | 1. 사용자가 분석 버튼을 누른다. 2. 시스템이 입력 결과를 구조화한다. 3. AI 분석 서비스에 요청한다. 4. 결과를 카드 형태로 출력한다. |
| 예외 흐름 | OCR 실패, LLM 실패, 타임아웃 발생 시 오류 또는 대체 경로를 표시한다 |

### 4.3 UC-09 캘린더 일정을 등록한다

| 항목 | 내용 |
| --- | --- |
| 목적 | 일정 정보를 기록하고 추후 조회할 수 있게 한다 |
| 주 액터 | 사용자 |
| 선행조건 | 로그인 상태여야 한다 |
| 후행조건 | 일정이 일정 목록에 반영된다 |
| 기본 흐름 | 1. 사용자가 캘린더 화면으로 이동한다. 2. 일정 제목, 시작/종료 시각을 입력한다. 3. 시스템이 저장한다. 4. 목록을 갱신한다. |
| 예외 흐름 | 날짜 형식 오류, 필수값 누락 시 저장하지 않는다 |
